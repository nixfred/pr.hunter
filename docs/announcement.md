Meet PR Hunter for Omarchy 🐙

Your projects, their GitHub PRs and issues, and a direct path back to work—all from the menu bar.

PR Hunter discovers projects across your running Herdr sessions, picks up new ones automatically, and remembers them after their sessions close. You can also add any local project folder yourself.

Click a project:

→ Already open in Herdr? Jump to its existing workspace and terminal.
→ Session closed? Start Herdr if needed and open the project workspace in the correct directory.
→ No Herdr installed? Open your default terminal in that same directory.
→ Prefer a regular terminal anyway? Use “Open terminal.”

When the project has a detected local agent, PR Hunter can hand it a detailed work brief: PR and issue numbers, links, repository paths, and instructions to review discussions and diffs, check CI, triage problems, implement fixes, test, and report what happened to every item.

Busy agent? Queue the handoff until it’s ready. Multiple agents? Choose the recipient. Want to inspect the instructions first? Preview the brief.

Filter your repositories and upstream projects. See open GitHub counts, with automatic updates and manual refresh. Merges and issue closures stay your decision.

Works with Claude, Codex and other agents recognized by Herdr. Opening a new session starts a shell; start your preferred agent when you’re ready to hand off work.

Open source. Built for Omarchy. Herdr optional.
